## 后续顺序与需要用户提供的材料

可继续独立推进：ENIP/CIP 明确子集与有界重组测试、证据接口/界面、M4 内部 API 和 Worker 子进程/资源约束、真实进程故障矩阵与文件发布恢复。默认仍由旧 Celery 承载；新原型没有注册到旧 API，停用原型即可恢复原有运行路径。此隔离方式不等于整栈回滚已验收。

## 实际结果

首次使用实现提交39ef9fd的Linux CI静态产物，连接本机真实队列API。正常上传成功，四条原始证据可查；点击候选连线时被响应节点遮挡，原始失败和截图保留。修复为辅助节点位于候选关系下方，不删除原始节点，未使用force click。后续使用本机成功构建的修复页面，标准点击通过。

# 首个真实双源样例最小接收清单

核对日期：2026-10-26。依据本地资料包 `references/SWaT_collection_20261024/dataset_catalog.json`（各release原始数据状态not_acquired）及 `pending_acquisition.md`，目前具备公开说明、规则参考和合成样例，没有已确认可用于本项目的授权同期原始双源片段。此结论限已登记资料，不能推断用户其他存储没有数据。

先接收一个同批次、同期、覆盖一次操作前后及若干工艺采样的小片段。可以仅正常操作，无需为初次字段核验同时提交完整攻击集。保留原文件；若裁剪，提供裁剪工具/命令、原文件SHA256、帧或时间范围、裁剪前后SHA256，避免裁去连接上下文。若超当前合成界面上限，走只读接收预检，不能伪标synthetic上传。

## 分开验收，不一次索要所有研究材料

1. **初次字段、映射和时间核验**：使用上述同期小片段，输出解析覆盖、未知字段、字典差异、映射冲突、时间区间和人工逐条复核表。失败项保留原始证据，不能转换为合成测试通过。
2. **正常区间验收**：另提供正常控制背景、覆盖区间与完整性说明，用于检查正常操作关联及误报；未具备。
3. **攻击区间验收**：另提供官方/独立实验开始结束、目标、操作与实际观测影响，标签来源与版本；用于复核攻击情境下解释，不进入分析逻辑；未具备。
4. **正式独立评估**：另提供独立标注、训练/校准/测试隔离、保留集和解封依据、固定匹配准则；用于准确性/误报/漏报及外推限制；未具备。不能用公开规则或算法输出生成gold。

软件仍可独立推进：本轮Celery上传执行、标准图、时间线、证据查询、完整性负例和相关回归均不依赖上述真实材料。真实数据入口、全量任务恢复/跨主机、完整回放、正式发布不在本轮范围；后续按原方案单独计划。

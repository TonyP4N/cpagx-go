## 固定统计语义

统计观察操作、工艺变化分别进行；候选关联独立列为未标注关系，不作攻击预测。
回放主指标采用最后一个已验证终态快照，同一稳定 ID 只计一次。首次可发表、撤回次数作为独立过程统计，不累计为预测数；不对 pending 或被撤回候选作最终命中。
网络单源只评价网络观测，工艺单源只评价工艺变化；双源按相同类别分别评价。有共同独立参考和同一分母才横比；投影视图不是实际单源分析实验，须区分。
匹配为 batch/kind/asset 相等、绝对时间差 <= 已冻结容差的最大基数一对一匹配。区间左闭右开。争议样本排除，争议正常区间并集从正常时长扣除。无分母返回 null 并给出原因。不报告路径准确率或工业指标。
固定输入/分析和回放版本/规则/配置/匹配策略/划分/窗口指纹后方可解封；声明审核、来源和时间并不等同系统证明独立性。

## 性能环境和限额预登记

参考：Ubuntu 24.04 x86_64，8 vCPU，16 GiB RAM，SSD；全站最多一个活动分析 attempt。
候选容量不降低：最多4抓包，每件64MiB、合计128MiB；CSV合计8MiB/10000逻辑记录/16列。
建议本轮显式性能配置：容器4 CPU、8GiB RAM/swap同上、64PIDs、1800秒墙钟、6000 CPU秒；输入只读；临时磁盘与持久交接各4GiB，预留至少8GiB空闲。输出1GiB，最多100000帧、10000操作、10000变化、100000候选、22000到达步骤、22000快照/44000修订，配置8MiB、单次证据查询100条/8MiB。以上属于待实现并实测的版本化新限制，不修改旧版本语义；任一界限先到即明确失败，不发表半产物。
规模：S=100操作/100工艺记录；M=1000/1000；L=10000/10000。分别生成支持子集的原始PCAP/CSV；另有4文件每件32MiB合计128MiB、单件64MiB，以及8MiB CSV的独立字节边界样例，不能以填充字节例替代L操作密度。每规模离线/回放各3次（第一次记录冷缓存条件，后两次热缓存；不能清缓存时注明未验证冷缓存）。边界+1文件/+1字节/+1记录及输出超限明确拒绝。
记录原始全部失败与成功：解析、关联、写盘、验证、排队/容器启动到终态、实际回放耗时；RSS/CPU/磁盘、证据查询延迟、积压和环境/镜像/提交/配置指纹。全链路<=1800秒，单次证据查询<=10秒；结果完整、引用全校验。达不到先定位，不自行降低目标。
本地环境仅可作开发证据；参考环境不可用时该验收受阻，不宣称通过。旧JSONL基准、R18倍速和CI绿灯均不替代。

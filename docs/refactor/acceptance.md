- 原始 PCAP/PCAPNG 的新解析器仅有 unsupported 接口；没有完成 CIP 字段、链路类型、分段重组、请求响应配对的真实验收。网络 JSONL 是合成适配器样例，不能包装为抓包解析成功。

- 新核心未接管旧 HTTP/Celery 请求，未实现 V3 路由、真实推断、回放、独立指标计算、前端证据工作流或 PostgreSQL 任务切换。

- 旧 V2 并发检查、PCAPNG 截断处理、启发式图关系等问题仍在，详见 `legacy-baseline.md`。旧评估脚本没有被当作 gold 或新核心评估器。

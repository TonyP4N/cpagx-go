# 第十七轮预登记：首版离线分析与配置机制

基线 `68977076ec3869fd3fa1c7e841c918e4b196840f`，分支 `refactor/m1-evidence-core`，核对时工作区干净。依据原方案 §4—7、R02—R07 及首版完成清单、支持矩阵、第十六轮补验收。冻结 RC1、默认入口和旧结果不变；本轮不进入 R18。

## 实施顺序与责任

1. 固定 `packet_pipeline` 为双源正式网络解析路径，独立原始字节/CSV 参考，最多四文件共享有界会话和重组状态。
2. 沿用 `dual_source` 增量扩展版本配置、时间/映射适用性、受控规则和来源声明。旧配置兼容，新字段显式启用，不覆写历史。
3. Go 数据集/预检/任务引用、隔离 Worker、标准产物、证据、成套备份同步扩展；真实来源仍须材料门禁，适用性不标为已验证。
4. 必要页面显示、实际 PostgreSQL/Worker 流程、三次独立重现、CLI 一致性、空库恢复和普通点击浏览器。通过后分阶段提交及完整远端 CI。

详细独立预期先于各模块实现写入 `round17-parser-scenarios.md`、`round17-core-scenarios.md`、`round17-service-scenarios.md`，测试答案不得由待测分析输出生成。

## 全链预登记验收（实现前）

| ID | 输入与操作 | 独立预期 / 禁止结论 |
|---|---|---|
| E01 | 独立生成 Write Attribute 请求在第一抓包、响应在第二抓包；CSV 从0变1，明确合成配置 | 2网络事件、1变化、1候选，2个原文件帧及2条CSV证据可查询；只表达候选，不表达物理成功、攻击或因果 |
| E02 | 同输入/配置独立运行3次，再经CLI与正式Worker各运行 | 规范化事件/图哈希一致；仅允许 run_id、attempt_id、启动完成/耗时时间、运行环境字段不同，任何语义字段差异失败 |
| E03 | 单源预检、补传另一抓包及CSV、再次预检、运行，再追加配置版本 | 两份旧报告/快照和旧运行不变；旧预检不能提交改变后的输入；引用原版本 |
| E04 | 所有任务终态停写成套备份；空数据库/新目录恢复 | 任务、attempt、全部输入配置和产物完整；API与普通点击页面可查询全部原始引用 |
| E05 | 删除/篡改原件、预检快照或产物；只读/未授权直接提交 | 明确拒绝可信查询/运行/备份；拒绝运行无任务或绑定，保留审计；不跳过校验 |
| E06 | 生成数据声明real，并有完整接口测试来源/授权/映射/时间说明 | 可以走同核心解析路径，输出synthetic=false及适用性未验证；报告清楚称接口分支测试，不能称收到真实样本 |
| E07 | real或synthetic缺来源/授权/批次/映射/时间材料 | 服务端明确拒绝跨源运行，单源接收仍可用；不得只禁按钮 |
| E08 | 第5抓包、总字节/帧/重组窗口/CSV/候选/输出超限 | 明确有界拒绝或按预登记的窗口耗尽未知状态，不能成功发布可信半产物 |
| E09 | 缺失/无效/零CSV值；缺映射、过期、一对多；时间依据缺失、漂移和区间不确定 | 缺失与零分开，原因和证据保留；未知/歧义不得选第一项或默认零偏移 |
| E10 | 状态变化、阈值跨越、有限工艺约束满足/不满足、单位冲突、恶意表达式 | 版本/参数/适用/缺失/支持反证及证据可见；未知不能当正常；任意代码拒绝，不执行 |

## 容量和结束条件

本轮实现最多4个抓包的输入及共享状态；执行仍采用明确有界开发资源，实际限额在实现记录中固定。首版候选目标保持每件64MiB、合计128MiB、CSV8MiB/10000记录、单活动attempt，留R19完整容量性能验收，不因本轮机制实现宣称达标。

受影响单元/契约/数据库/服务/备份/浏览器通过，保留R16两处操作顺序回归；最终提交完整CI成功才关闭本轮。软件实现、合成工程验收、真实数据验收分别记账。真实授权同期PCAP/CSV、字段设备与时钟依据、独立标注/保留集和真实历史实例仍为外部材料缺口；不妨碍本轮软件实施。

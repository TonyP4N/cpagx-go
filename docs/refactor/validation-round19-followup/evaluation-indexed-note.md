# 显式评估 V2 本机开发验证

版本为 `indexed-temporal-one-to-one-v2` / details `2.0.0`。旧 `evaluation.py`、默认 `evaluate_detailed` 及旧 500 上限不变；冻结 bundle 的版本接入由独立原件适配分工完成。

- `evaluation-indexed-tests.log`：9 项独立测试成功，覆盖 20,001 预测/20,000 标注的手写期望 TP19,999、FP2、FN1；22,000 双侧同一时间的密集匹配；22,001 明确拒绝；1,225 小集合组合的独立穷举最大匹配；争议并集、零分母、版本/来源拒绝。兼容候选明细有总数、最多20个示例与截断标志，不隐式截断统计。
- `evaluation-indexed-dense-22000.json`：首次原始测量。匹配 0.115 秒；整个评估函数 4.279 秒墙钟、1.692 CPU 秒，进程生命周期 RSS 高水位约116MiB，结果规范序列化约2.46MiB。
- `evaluation-indexed-dense-22000-attempt2.json`：可复现探针的独立重复；保留代码指纹、时间、原始测量和范围说明，不能用较快样本替代其他样本。
- `evaluation-indexed-probe.py`：复现上述密集输入的开发探针，不读取预测产物来生成金标准。

未发生非预期的评估失败；超预算、无分母和不可信输入均为保留的预期拒绝。曾观察完整 `tests/evaluation` 65项成功（67.409秒，正式 bundle V2 合并前），该次终端流没有另存为原始日志，故不冒充本目录原始记录。

这些仅证明本机合成评估函数，不证明完整原始产物、Worker、正式参考环境、服务查询时延或真实工业材料验收。22,000 上限作用于最终操作/变化评估事件总数，不能把10,000行×16列可能产生的160,000原始观测宣称已全部评分。超出最终事件上限会拒绝，不截断。

## 本轮复核中修复的缺口

- 容量重建不能仅凭文件发现 attempt：补入数据库协调器执行发现，文件与账本同时丢失时保留未证明执行。
- 不可读目录遍历不得被当作空目录；任务 ID、输入相对路径必须与已有契约一致。
- 运维快照包含控制证据与容量账本；备份前要求停写与终态证据，恢复拒绝覆盖已有目录、数据库或报告。
- 打包入口的数据库迁移登记、独立恢复周期、下载产物校验在离线演练前共同核对。离线演练复现并修复数据库名称、就绪检查与输入命名空间问题；前修复输入被 API 拒绝的证据见 `offline/pre-fix-input-prefix/`。

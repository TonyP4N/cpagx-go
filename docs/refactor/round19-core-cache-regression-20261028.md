## 定位与修复

新增的跨写入平面值缓存，在每次访问时先序列化完整值，再检查缓存，抢在原有的同步单根对象memo之前；重复SourceRef即使原本可O(1)复用，也再次序列化。因此改变为先查询同步单根memo，未命中才计算完整值键；跨根仍清空对象memo，跨写缓存继续绑定完整规范字节，负零/类型/字段变化均不能误命中。

固定配额未增加。共享逻辑内容、Merkle摘要、旧版本和负例均保持；21项存储、3项extent/突变/负零/有界缓存、5项完整回放语义组通过。真实规模收益尚需dev3同配额实跑，不能仅凭上述实现判断优化成功。

## 原件拒绝独立诊断

dev2首次受控目录绑定挂载导出拒绝`evidence file changed`。独立记录证明CSV的ctime在约3秒内变化，SHA/dev/inode/size/mtime不变；不能单凭此判定某云软件原因。保留严格核验，显式选择core-local-scratch-1后整链通过，并核对受控交接全部文件SHA和冷查询。环境准备的tag查询拒绝、实际core拒绝、调度主动停止和性能截止分别登记，不混成同一类失败。

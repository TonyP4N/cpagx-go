## 固定开发环境与测量定义

macOS ARM64上的Docker Desktop，实际VM资源以每格环境记录为准，不等于Ubuntu24.04 x86_64/8vCPU/16GiB/SSD参考环境。容器固定4CPU、8GiB memory/memory-swap、4GiB tmpfs、网络禁用、只读rootfs、128进程；Docker VM实际内存若小于容器上限必须同时报告。进程RSS不是容器内存；CPU配额不是累计CPU秒；阶段RSS是累计高水位不是阶段新增分配。嵌套阶段不得求和。

每格全新0700本机暂存目录，原件和配置固定；export→新进程全来源verify→冷/重复query→完整复制和SHA库存核对→交接后新进程query，全链1800秒。每页10秒/8MiB/100条；OS冷缓存未验证。保留暂存与受控副本，交接时暂存与/tmp合计占用纳入4GiB限制。来源/输出/节点变化必须拒绝。1GiB输出由发布器最终限额与控制器采样/终态完整目录检查执行；宿主bind目录没有独立文件系统硬配额，不能声称具备该隔离保证。4GiB/tmp是实际tmpfs上限，保留暂存副本与/tmp合计另行采样核对。

本表六格仍使用56原镜像；它们不包含5d修复。L回放从只读git56/7cc验收器源码视图执行，避免工作区变动污染身份。后续修复的源文件差异、受影响复验另列，不能把小数值边界检查当4PiB完整分析通过。4PiB仅是共享逻辑计数护栏，物理1GiB与单页8MiB不变。

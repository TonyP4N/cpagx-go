## 本轮范围与预登记验收

仅 `synthetic_normalized_network` JSONL + process CSV +现有synthetic-demo profile。阶段分为：P（构建索引与两源解析）、E（现有pipeline索引/解析/规范化/观测图/写盘）；不是网络协议解码或关联性能。回放积压不适用，明确null，不能填0。

固定每源100/1000/5000条、每阶段各3个全新子进程；每样本预期3N事件，图仅3N节点、0边。记录字节/秒、事件/秒、阶段耗时、进程峰值RSS（不是tracemalloc）、输入/配置/结果指纹、环境版本和逐样本数据；按规模/阶段给min/median/max，不能只选最好值。

预登记工程保护上限：Docker Linux 2 CPU配额、512 MiB内存/同额swap上限、64 PID、256 MiB临时文件系统；单样本含生成与验证60秒上限，阶段RSS不高于512 MiB。此为本次测试约束，不是原方案建议8vCPU/16GiB基准机器、最低配置或工业性能承诺；不制定事后最低吞吐阈值。Linux架构/内核/Python/容器限制与镜像ID实际登记，跨主机/架构不直接比较耗时。

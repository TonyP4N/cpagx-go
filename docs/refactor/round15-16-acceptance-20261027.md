## 第十六轮新增能力

- Go 正式服务提供静态工作台及 `/api/v3`，另一回环端口保留内部 M4 协议；不需要各轮临时代理，不导入旧 FastAPI/Celery。兼容路径、RC1 与当前默认部署不改。
- PostgreSQL 增加十张目录/权限/审计表，持久保存数据集、原件 SHA、声明来源/批次、配置版本、预检报告及任务引用；运行绑定与 `m4_jobs` 同事务。
- 管理员、分析员、只读者及逐数据集 ACL；用户会话和内部执行凭据分离。关键写入与审计同事务，证据/下载审计失败拒绝读取；鉴权拒绝另留不含秘密的审计。
- 正式 Worker 服务沿用既有隔离执行和独立定期恢复；CLI 调用同一公共 API。没有另写核心、状态系统或协议解析器。
- 原件流式上传、长度/哈希校验、幂等键冲突、不可变配置版本、实际两版本执行；真实来源允许接收和单源元数据核查，但当前 synthetic-only 核心拒绝真实双源运行。
- 终态停写备份新增目录、配置、授权和审计；空数据库/新目录恢复后校验引用，撤销旧会话，再经 API 和浏览器读图、四条原始证据及下载。

## 发现与修复

| 问题/证据 | 修复与回归 |

| 批次冲突最初为200+错误报告，与预先计划不符 | 保存可追溯报告/审计后返回409 `batch_conflict`；实际专用冲突测试通过 |
| 验收辅助脚本 Path.open 不接受 opener | 使用内建 open 以0600创建配置；正式集成通过，无服务运行语义变化 |

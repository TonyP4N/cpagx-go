# ADR 0001：证据优先的渐进重构

日期：2026-10-24。状态：M1 已采用；后续服务架构为设计约束，尚未切换。

## 决策与边界

保留 Go / Python / TypeScript。Go 负责 API、权限和任务事实；Python 纯核心负责标准化与分析；TypeScript 只呈现服务结果。当前新增核心可脱离 FastAPI、Celery、Redis、Neo4j 运行，旧服务保留。先建立独立调用入口，不将尚未验证的新解析器接入旧服务默认路径。

每个对象有显式 schema_version；来源证据包含文件 SHA-256 和帧号或 CSV 逻辑记录号/列名，原始时间不丢弃。没有时区依据时 UTC 为空。身份、操作或响应无法确认时保留未知，不猜测 IP、标签或因果关系。初期不计算攻击成功概率。

M1 的网络输入是显式 synthetic 的适配器记录。PCAP/PCAPNG 只建立失败明确的接口，不能视为真实协议解析已完成。CSV 按显式配置读取，不插值、不补零、不自动校准时间。两源可同时输入，但各自输出观测，跨源时间对齐及关联禁用；图可断开。

核心输出规范 JSON、证据索引和带校验值的运行清单，Neo4j 为后续可选适配器。不可变运行目录禁止覆盖；事件/图指纹排除运行编号和接收时间等易变值。原始输入不可修改，规则变更应新建运行。

## 后续任务事实与部署

目标为 Go + Python Worker + PostgreSQL，只有 Go 持有业务库凭据。Worker 使用内部 API 获取租约和递增 fencing token，按 attempt 产生输出，Go 校验后提交；至少一次执行和幂等发布，不承诺 exactly-once。取消、过期租约、崩溃恢复、重复提交及磁盘故障须通过故障矩阵后再切换。M1 不实现或替换现有队列，不改变生产部署默认。

## 数据权限与评估隔离

公开资料仅为来源参考，规则 PDF 不作 gold；批次映射及 Delta 阈值须原始批次确认。真实数据和授权下载链接不进 Git。annotations 与分析输入分离，正式评估要求独立标注、固定留出集和不依赖测试标签的时间校准。合成测试仅验证软件行为，不提供工业有效性结论。

## 代价与退出条件

保留两套入口增加短期维护成本，但可独立回滚。M1 完成标准事件/证据可复核、合成样例可运行和异常边界测试；不将 M2/M3/M5 真实解析、对齐、关联和准确性评估列为已完成。服务迁移需另过 M4 故障恢复验收。
